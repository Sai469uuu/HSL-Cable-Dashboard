⚡ HSL Cable Management Dashboard

Overview:
Interactive dashboard built with Streamlit, Plotly, and Pandas to track cable length variances at Hindustan Shipyard Limited (HSL).

Problem Solved:
Centralized scattered data to quickly identify high-variance cables (>20%), optimize procurement, reduce material wastage, and prevent project delays.

Features:

Line chart: Length Variance Over Time

Pie chart: Procurement Category Share

Bar chart: Average Variance by Cable Size with variance >20% highlighted

Sidebar filters: Procurement Category & Cable Size

Downloadable high-variance cables table

Impact:
Enabled faster decision-making, minimized cost overruns, and improved operational efficiency.
